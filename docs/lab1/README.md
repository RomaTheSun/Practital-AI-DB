# Лабораторна 1 · LLM Bench

## Метод

Метод буде доповнено точними датами, SHA коміту промптів, `dataset_sha256` та результатами після незмінюваних прогонів кроку 03. Набір заздалегідь поділено на `dev` (8), `test` (25) і зафіксовану хмарну підмножину `q15` (15). Промпти налаштовуються лише на `dev`; `test` і `q15` використовуються тільки для звітування.

Порівнюються `v0` (zero-shot), `v1` (роль, правила, JSON), `v2` (`v1` плюс усі 8 `dev` few-shot) і `v4` (теги, екранування закриваючого тегу, правило недовіреного вводу). Локальна `qwen3:4b` проходить увесь `test`, а `gemini-3.8-flash` — `q15`. Точність рахує детермінований `score.py`; технічні помилки API не входять у знаменник. Для кожної частки подається `n` і 95% інтервал Вілсона.
