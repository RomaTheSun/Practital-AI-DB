# Лабораторна 1 · LLM Bench

## Метод

Набір `data/golden.jsonl` (`dataset_sha256=f12b72c7837d4bea812f26b6f58cc5cca5559aa0f4b90720b36567b8524c0f7b`) заздалегідь поділено на `dev` (8), `test` (25) і зафіксовану хмарну підмножину `q15` (15). Промпти налаштовувалися лише на `dev`; `test` і `q15` використовувалися тільки для звітування. Після dev-перевірки всі промпти й чотири гіпотези зафіксовано комітом `2cc4a1c` до першого тестового рядка; кожен результат містить SHA цього коміту та SHA-256 конкретного промпту.

Порівнюються `v0` (zero-shot), `v1` (роль, правила, JSON), `v2` (`v1` плюс усі 8 `dev` few-shot) і `v4` (теги `<input>`, екранування `</input>`, правило недовіреного вводу). Локальна `qwen3:4b` працює через Ollama з фактичним контекстом 16 384, `temperature=0`, `seed=7`, `reasoning_effort=high`, `max_tokens=4096`; вона пройшла весь `test` 2026-10-27. Хмарна `gemini-3.8-flash` має `reasoning_effort=low` і проходить `q15`: 2026-10-27 отримано 18 успішних відповідей, 2026-10-29 — ще 12; разом 30 із потрібних 60. Free tier повідомляє добовий ліміт 20 запитів; перервані генерації й запити, що отримали 429, також витрачають доступну кількість спроб.

`score.py` детерміновано прибирає `<think>` і JSON-огорожі, спершу читає `{"label": ...}`, потім однозначну жирну мітку, потім рівно одну різну допустиму мітку в тексті. `correct` — нормалізований точний збіг із `expected`; дві різні мітки або відсутня фінальна мітка дають `None`. Парсер і тести були закомічені до `test`, після прогонів `correct` не перераховувався. Рядки 429/5xx/timeout не входять у знаменник, а `--resume` пропускає кожен ID з успішною спробою.

Для accuracy звітуються `k/n` і двобічний 95% інтервал Вілсона; через малий `n` варіант не називається кращим, якщо інтервали перетинаються. Додатково порівнюються `hard`, окремі приклади `injection`, flips відносно `v0`, valid rate, токени, медіана затримки й оцінена вартість. Сирі локальні результати та першу порцію Gemini зафіксовано комітом `174910d0fc4d39af0948cff0e7a2e6f6a1082a02`.

Відхилення від протоколу: першу хмарну порцію запущено чотирма однопотоковими процесами паралельно, після чого добова квота була вичерпана; її затримки не використовуються для порівняння. Перед другою порцією приховані SDK-retry вимкнено, transport-timeout встановлено у 900 секунд, а добове `quota exceeded` більше не повторюється раннером. Параметри моделі, промпти й scoring не змінювалися. Незавершені хмарні значення в таблиці позначають лише прогрес, а не фінальний результат.
