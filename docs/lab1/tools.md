# Крок 05 · Виклик інструментів: власний цикл

## Метод

- Інструменти: `lookup_workload` повертає синтетичний профіль навантаження, `lookup_requirement` — обов'язкову вимогу. Некоректний формат коду повертається в цикл як `tool_error`, відсутній код — як `found: false`.
- Кейси: `data/tool_cases.jsonl`, 8 шт.; очікувані інструменти записані в `tags`.
- Промпт: `prompts/t1.md`; `max_steps` = 6, `token_budget` = 20000; моделі: локальна `qwen3:4b` і хмарна `gemini-3.8-flash`.

## Висновок

Буде дописано після локального та хмарного прогонів із посиланнями на рядки трас.

## Чому це може не відтворитися

- Модель може завершити відповідь без виклику, надрукувати виклик у тексті або обрати інший порядок двох інструментів.
- Версія моделі, шаблон tool calls у сервері та реалізація підрахунку токенів можуть змінитися.
- Безкоштовна хмарна модель може повертати `429` або `503` до виконання циклу.
