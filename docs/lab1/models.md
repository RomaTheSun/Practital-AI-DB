# Картки моделей

Стан джерел перевірено 2026-10-27. Ціни вказано за 1 млн токенів; локальний запуск не має API-тарифу, але споживає ресурси власного комп'ютера.

## `local` — Qwen3 4B через Ollama

- Тип і роль: модель з відкритими вагами, основна локальна умова експерименту.
- ID у реєстрі: `qwen3:4b`; сервер OpenAI-compatible `http://localhost:11434/v1`; фактичний контекст стенда — 16 384 токени.
- Параметри кроку 03: `temperature=0`, `seed=7`, `reasoning_effort=high`, `max_tokens=4096`.
- Можливості: thinking/non-thinking, tools; локальний Ollama також підтримує JSON schema. Ліцензія ваг — Apache-2.0.
- Дані й ціна: запити не залишають локальний сервер; API-ціна `$0 / $0`; безкоштовний рівень — так; навчання на введених даних — ні.
- Джерела: [Ollama: qwen3](https://ollama.com/library/qwen3), [Qwen/Qwen3-4B](https://huggingface.co/Qwen/Qwen3-4B) (звернення 2026-10-27).

## Qwen3 8B через Ollama

- Тип і роль: модель з відкритими вагами, більша локальна альтернатива; у вимірювання кроку 03 не входить через обмеження часу й пам'яті ноутбука.
- ID: `qwen3:8b`; Ollama показує ваги близько 5,2 GB і контекст 40K.
- Можливості: reasoning, tools, багатомовна робота; ліцензію конкретного артефакту треба перевіряти перед розгортанням.
- Дані й ціна: локально, API-ціна `$0 / $0`; навчання на введених даних — ні.
- Джерело: [Ollama: qwen3](https://ollama.com/library/qwen3) (звернення 2026-10-27).

## `gemini` — Gemini 3.8 Flash

- Тип і роль: закрита хмарна модель, друга умова експерименту на зафіксованій підмножині `q15`.
- ID у реєстрі: `gemini-3.8-flash`; OpenAI-compatible endpoint Gemini API; контекст до 1 048 576 вхідних і 65 536 вихідних токенів.
- Параметри кроку 03: `reasoning_effort=low`; модель підтримує thinking `low`, `medium`, `high`, structured outputs і function calling.
- Ціна до 2026-12-31: `$0.75 / $3.75` на платному рівні; free tier — без оплати. На безкоштовному рівні вміст може використовуватися для поліпшення продуктів, тому надсилаються лише синтетичні дані.
- Джерела: [картка Gemini 3.8 Flash](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash), [ціни Gemini API](https://ai.google.dev/gemini-api/docs/pricing) (ціни зафіксовано 2026-10-10, перевірено 2026-10-27).
